# تطبيق «أسبوعي» (My Week) 🌟
### جدول المذاكرة، الصلوات، والأنشطة للأبطال

تطبيق ويب تفاعلي باللغة العربية مخصص للطفل والأسرة، يساعد في تنظيم الروتين اليومي وجدول المذاكرة، الفروض المدرسية، الصلوات الخمس ودرس القرآن، النوادي الرياضية، وأوقات الراحة والترفيه بأسلوب مبهج وبدون أي ضغوط.

---

## ✨ المميزات الرئيسية

- ☀️ **شاشة اليوم الذكية**: عرض أنشطة اليوم بتسلسل زمني، بطاقة للنشاط الحالي والقادم، وأزرار إنجاز فورية تمنح نجوماً مشجعة.
- 🕌 **الصلوات الخمس وحفظ القرآن**: دمج الفروض اليومية ودرس القرآن في الجدول مع عبارات ثناء إسلامية لطيفة.
- 🗓️ **الجدول الأسبوعي الكامل**: استعراض ومتابعة الأسبوع كاملاً، مع إمكانية إعادة الجدولة السريعة بلمسة واحدة.
- ⏱️ **مؤقت التركيز اللطيف**: فترات مذاكرة واستراحات ممتعة مدعومة بنغمات Web Audio رقيقة وتفاعل بصري دافري.
- 🏆 **برطمان النجوم والملصقات**: مكافآت عائلية تحفيزية وألبوم ملصقات كرتونية تفتح تدريجياً مع الإنجاز.
- 🎮 **واحة الألعاب «مغامرة بطل النجوم» (إصدار 10 سنوات)**:
  - لعبة أركيد فضائية بصورة الطفل الكرتونية.
  - 3 قلوب طاقة، نيازك سريعة، سحب رعدية، قوى خارقة (🧲 مغناطيس، ⚡ تيربو تحطيم، 🛡️ درع حماية، 💖 قلوب طاقة)، ومضاعف كومبو حتى x5.
  - محكومة بالكامل بإذن وليّ الأمر بمسألة رياضية أو رمز PIN، مع مؤقت إغلاق تلقائي آمن.
- 👥 **نظام الحسابين المزدوج (Child & Parent Mode)**:
  - **حساب الطفل 👦**: يعرض كافة الميزات اليومية للطفل، مع إخفاء تبويب إعدادات ولي الأمر بالكامل ومنع الوصول إليه.
  - **حساب ولي الأمر 👑**: صلاحيات كاملة وتخصيص للمواد، أوقات المدرسة، النوادي، والتحكم في إذن اللعب، محمي برمز PIN سري.
- 📱 **تطبيق تقدمي PWA وتوافق كامل مع الموبايل والتابلت**:
  - يدعم العمل بدون إنترنت (Offline Cache).
  - تثبيت فوري كأيقونة على الشاشة الرئيسية للآيفون، الآيباد، وهواتف الأندرويد.
  - تصميم متجاوب فائق الدقة يناسب هواتف الآيفون (iPhone 11 إلى iPhone 18).

---

## 🚀 كيفية التثبيت على الهاتف أو التابلت مجاناً (PWA)

1. افتح الموقع من المتصفح في هاتفك (Safari للآيفون/الآيباد أو Chrome للأندرويد).
2. اضغط على زر **المشاركة (Share)**.
3. اختر **«إضافة إلى الشاشة الرئيسية» (Add to Home Screen)**.
4. سيفتح التطبيق بشاشة كاملة مثل التطبيقات المحملة من المتجر تماماً وبدون أي شريط متصفح.

---

## 🛠️ تشغيل التطبيق محلياً

```bash
node server.js
```
ثم افتح:
- محلياً: `http://localhost:3456/`
- عبر الواي فاي على نفس الشبكة: `http://<IP_الكمبيوتر>:3456/`

---

## 🌐 النشر مجاناً على GitHub Pages

1. ارفع المشروع إلى مستودع (Repository) على حسابك في GitHub.
2. ادخل إلى **Settings** > **Pages**.
3. في خيار **Build and deployment**:
   - اختر **Source**: `Deploy from a branch`.
   - اختر **Branch**: `main` والمجلد `/(root)`.
4. اضغط **Save**، وخلال دقيقة واحدة ستحصل على رابط مباشر مجاني يعمل مدى الحياة!
